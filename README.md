# PocketSmart AI

PocketSmart AI is a smart budget and recommendation assistant.

## Features

- Home Interior Budget Planner
- Party Budget Planner
- Jewelry Recommendation Planner
- Optional outfit image upload
- AI-powered recommendations
- Budget allocation suggestions

## Technologies Used

- Python
- FastAPI
- HTML
- CSS
- JavaScript
- Google Gemini AI

## Installation

Install Python 3.10 or newer.

Install the required libraries:

pip install -r requirements.txt

## Run the Project

uvicorn main:app --reload

Open this address in your browser:

http://127.0.0.1:8000

## AI Configuration

Create a private .env file and configure your Gemini API key.

Never upload your private API key to GitHub.

## Note

Recommendations are estimates. Always verify actual product prices and availability.
